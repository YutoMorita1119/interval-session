# 結果画面と操作デモの改善計画

## 解決する問題とその理由

現在の結果画面は双方のお題を表示するだけで，自分の最終予想が正しかったかを直接確認できず，開始画面へ戻る操作もない．また，開始画面のチュートリアルは参加方法，簡単な音配置，模擬送信までに留まり，初見の一人が「別々のお題を音で伝え合い，解釈と予想を重ね，履歴と結果を確認する」システム全体を把握しにくい．

研究参加者へ余計な印象を与えず，一人の閲覧者には実セッションを作らなくても約2分で主要な流れが伝わる構成へ改める．

## 成功基準

- 結果画面の両端に「あなたのお題」と「相手のお題」を置き，中央に双方向の最終予想を表示する．
- 「あなた → 相手」と「相手 → あなた」の各方向に，予想，○／×，一致／不一致を文字で表示する．
- 最終予想は，各roleの最終担当ターンを採用する．7ターン制ではホストのTURN 7，ゲストのTURN 6が届くまで判定しない．
- promptとreflectionの到着順が前後しても，読込完了後に結果が更新される．
- 結果画面から開始画面へ戻り，新しいセッションの作成または参加ができる．
- 戻る操作で音声，Firestore listener，セッション状態，秘密データ，入力値，`sessionStorage`を解除し，完了済みFirestoreデータ自体は削除しない．
- 開始画面で「実セッション」と「一人で流れを確認する」の2導線を判別できる．
- デモだけで，2人用，別々のお題，7ターンの往復，相手の音を受けた編集，解釈と予想，履歴，終了時の答え合わせを理解できる．
- デモではセッションを作成せず，Firestoreのread/writeを行わない．ページ読込時の匿名認証は現状どおり維持する．
- 実際の6つのお題，感情を誘導する例文，宣伝的なコピーをデモへ追加しない．
- 360px程度の画面幅とキーボード操作でも完了できる．

## スコープ

対象は結果ダイアログ，最終予想の判定ロジック，開始画面へ戻る処理，開始画面のデモ導線，3段階の非通信デモ，関連するCSS，README，自動テストである．Firestore schema，Security Rules，ゲームの7ターン進行，実際のお題，音声エンジン，1人用ゲームは変更しない．

## 制約と依存関係

- Firebase匿名認証と既存のrole別private/reflectionsを使用する．
- 正誤は，選択肢とお題の日本語文字列の厳密一致で判定できる．
- 終了後に相手側private/reflectionsが非同期で届くため，結果表示は購読更新のたびに再描画する．
- デモはブラウザ内の一時状態だけを使用し，gatewayの作成・参加・確定処理を呼ばない．
- 研究システムとして，中立的な文言と既存の簡素なデザイン方針を維持する．
- GitHubへのpushとFirebase Hostingへのデプロイは，ローカル実装・レビュー完了後に別途承認を得る．

## 実装の順序

1. roleごとの最終担当ターンの予想を取得し，相手のお題との一致を判定する純粋関数を追加してテストする．
2. 結果画面へ双方のお題を両端に置き，その間へ「あなた → 相手」「相手 → あなた」の予想と一致／不一致を追加する．双方の判定データが揃うまでは読込中とする．
3. promptとreflectionの各listenerから結果を再描画し，非同期読込中の表示を扱う．
4. listener，音声，sessionStorage，秘密状態，入力，ダイアログを解除して開始画面へ戻る処理を追加する．
5. 開始画面を，実セッション操作と「一人で流れを確認する」デモ導線に整理する．
6. デモを3段階へ再構成する．第1段階は2人・別々のお題・7ターンの全体像，第2段階は灰色の削除，空きマスへの追加，再生のチェック式練習，第3段階は模擬履歴と最終予想の答え合わせとする．
7. デモの初回自動表示を廃止し，開始画面の明示ボタンから任意に開く．閉じた場合は一時状態と音声を破棄する．
8. PC幅と360～390px幅，キーボード操作，戻る後の再入室，正解・不正解を検証する．
9. 独立したコードレビュー後，承認を得てGitHubとFirebase Hostingへ反映し，本番2タブで確認する．

## 確認したい仕様

- 結果画面では，あなたと相手の最終予想を双方向の矢印で対称に表示する．デスクトップは左右，モバイルは縦方向へ並べ替え，矢印の文字ラベルも残す．
- デモは初回に自動表示せず，「操作と結果を見る」ボタンから任意に開始する．実験参加者の開始操作を遮らないためである．
- デモ中もページ読込時のFirebase匿名認証は行うが，セッションデータは作成・読込・保存しない．
